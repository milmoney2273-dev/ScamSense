# 🛡️ ScamSense AI

ScamSense AI is a free-first cybersecurity project that analyzes suspicious messages and identifies potential scam warning signs using a transparent rule-based detection engine.

The project is designed as an educational tool for understanding how explainable security heuristics can be combined with a modern web application.

## 🚀 Features

- 🔎 Suspicious message analysis
- ⚠️ Risk scoring from 0–100
- 🧠 Explainable detection signals
- 🔐 Sensitive-information detection
- 💰 Payment-pressure detection
- ⏱️ Urgency detection
- 🎭 Possible impersonation detection
- 🔗 Suspicious URL analysis
- 🌐 IP-address URL detection
- 🔗 URL-shortener detection
- 🧩 Punycode detection
- 🏷️ Brand-impersonation heuristics
- 🌲 Deep-subdomain detection
- 📊 Analysis dashboard
- 🗃️ SQLite analysis history
- 🧹 Clear-history functionality
- 🧪 Automated unit tests
- 📱 Responsive interface
